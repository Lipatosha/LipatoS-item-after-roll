# LipatoS - Расход предметов после броска

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который откладывает расход зарядов и количества предмета у обычных игроков до фактического броска кубика.

Если окно броска закрыто или бросок отменён, ресурс предмета не расходуется.

## Версия

**1.0.1**

## Совместимость

- Foundry VTT: **14.367**
- D&D 5e: **6.0.3**

## Возможности

- списывает заряды и количество предмета только после состоявшегося броска;
- если бросок отменён, использование предмета не расходуется;
- не изменяет расход заклинаний — модуль работает только с обычными предметами;
- скрывает у игроков раздел **«Расход»** в окне использования предмета;
- переводит **Drink** как **«Выпить»**;
- заменяет кнопку **«Использовать характеристику»** на **«ИСПОЛЬЗОВАТЬ»** без иконки;
- ГМ не ограничивается модулем.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-item-after-roll/main/module.json`
